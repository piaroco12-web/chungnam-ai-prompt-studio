3고치기 · 한 문장씩 더하기

계산기가 나온 뒤 Build 왼쪽 채팅창에 하나씩 넣습니다. 한 번에 하나만 고치는 게 안전합니다.

계산 과정 보여 주기

결과 아래에 계산 과정을 한 줄씩 보여 줘. 공제 대상 금액 → 공제율 → 세액공제액 순서로.

금액 입력 편하게

입력 칸을 만원 단위로 바꾸고, 결과 숫자에는 쉼표를 찍어서 '148만 5천원'처럼 읽기 쉽게 보여 줘.

한도 초과 알림

연금저축이 600만원을 넘거나 연금저축과 IRP 합계가 900만원을 넘으면, 입력 칸 아래에 '한도를 넘은 금액은 공제되지 않아요'라고 알려 줘.

두 경우 비교

'연금저축만 600만원 넣을 때'와 'IRP까지 합쳐 900만원 채울 때'의 세액공제를 나란히 비교하는 표를 추가해 줘.

보기 좋게 다듬기

글자를 크게 하고, 휴대폰에서도 스크롤 없이 한 화면에 보이게 정리해 줘. 입력 칸 옆에 무엇을 넣는지 짧은 설명도 달아 줘.

초기화 버튼

입력값을 한 번에 지우는 '다시 계산' 버튼을 결과 아래에 넣어 줘.

4점검하기 · AI 답을 그대로 믿지 않기

검산 시키기

계산기 결과와 손 계산을 비교하게 합니다. 연습지 검산 칸과 맞춰 보세요.

방금 만든 계산기를 검산해 줘. 총급여 5,000만원, 연금저축 600만원, IRP 300만원일 때 손으로 계산한 과정과 계산기 결과를 나란히 보여 주고, 다르면 고쳐 줘.

빠진 조건 찾기

이 계산기가 실제 연말정산 결과와 다를 수 있는 이유를 3가지 알려 줘. 각각 확인할 수 있는 공식 자료(국세청 등)도 적어 줘.

맞장구 확인

내가 틀린 숫자를 말해도 맞다고 하지 말고 바로잡아 줘. 연금저축 세액공제 한도가 연 1,000만원 맞지?

+ETF 설명서 읽히기 · 실습 ③

바로가기 화면의 "실습 ③ 자료"에서 간이투자설명서 .md를 내려받아 Gemini에 올린 뒤 씁니다.

근거와 쪽수로 정리하기

첨부한 간이투자설명서에만 근거해서 답해 줘. 총보수, 투자위험등급, 추종 지수, 환율 변동 위험 여부를 표로 정리하고 항목마다 쪽수를 적어 줘. 문서에 없으면 '문서에 없음'이라고 써 줘.

문서에 없는 것 물어보기

AI가 문서 밖 내용을 지어내지 않는지 확인합니다.

이 문서만 보고 답해 줘. IRP 계좌에서 이 ETF를 사면 세금은 어떻게 돼? 문서에 근거가 없으면 없다고 말해 줘.

표가 제대로 읽혔나 확인하기

1쪽의 보수 표에서 '총보수'와 '총보수·비용'은 각각 몇 %야? 두 값이 왜 다른지, 표의 어느 칸을 읽었는지 같이 알려 줘.

긴 설명서에서 찾기 (심화)

첨부한 투자설명서에서 분배금은 언제, 어떻게 지급하는지 찾아 줘. 근거 문장과 쪽수를 그대로 인용해 줘.

5다른 계산기 만들어 보기

규칙을 AI가 먼저 정리하게 하고, 국세청 자료로 확인한 뒤 만들게 합니다. 규칙은 해마다 바뀔 수 있습니다.

월세 세액공제 계산기

월세 세액공제 계산기를 만들고 싶어. 2026년 귀속 기준 공제 조건과 공제율을 먼저 표로 정리하고 출처를 알려 줘. 내가 국세청 자료로 확인하고 '맞아'라고 하면 그때 만들어 줘. Gemini API는 쓰지 말고 계산만 해 줘.

신용카드·체크카드 소득공제 점검표

신용카드와 체크카드 사용액을 넣으면 소득공제를 받기 시작하는 기준을 넘었는지 보여 주는 점검표를 만들고 싶어. 2026년 귀속 기준 규칙을 먼저 표로 보여 주고 출처를 알려 줘. 확인받은 뒤에 만들어 줘.

고향사랑기부 세액공제 계산기

고향사랑기부금 금액을 넣으면 세액공제와 답례품 한도를 보여 주는 계산기를 만들고 싶어. 2026년 기준 구간별 공제율을 먼저 표로 보여 주고 출처를 알려 줘. 확인받은 뒤에 만들어 줘.

우리 반 용돈 기입장 (경제 수업용)

연말정산 대신 수업에 바로 쓰는 응용입니다. 학생 이름 대신 번호를 씁니다.
